GPT白龙娘动态桌宠 v0.4.0 —— 新手安装与使用说明

适用：Windows 10/11，64位Intel/AMD电脑。Windows ARM、macOS和Linux不在本包支持范围。
这是解压即用的便携版，不用安装Python。本包不是OpenAI官方产品。

一、应该下载什么
普通使用者下载 bailong-desktop-pet-v0.4.0-windows-x64.zip。
repository.zip 和 GitHub 的 Source code 是源码，不是完整安装包。
项目地址：https://github.com/jingh12312-rgb/bailong-desktop-pet
本地生成发布包不表示GitHub已经更新，以实际发布页面为准。

二、安装和启动
1. 先退出旧版桌宠。如果开启过自动启动，用旧文件夹的“关闭随GPT自动启动.cmd”关闭。
2. 右键下载的ZIP，选择“全部提取”，解压到自己的文件夹。
3. 打开解压后的 BailongPet 文件夹，双击 BailongPet.exe。
4. 等待“整理好裙摆和小翅膀”的准备进度完成，桌宠就会出现。
不要在压缩包里直接启动，也不要只拿出EXE。_internal、outputs、app和EXE必须放在一起。
可给EXE创建桌面快捷方式。启动会预加载25段动画，以减少点击卡顿，因此需要一定启动时间和较多内存。
桌宠本身、待机、拖拽、互动和托盘功能均可离线使用，不必打开GPT。

三、基本操作
单击：从15个互动和5个工作动作中随机互动，显示台词4秒。
双击：查询Codex剩余额度；查询动画只播放一次。
按住左键拖动：拖拽动作；松开：2秒落地；屏幕边缘会限制位置。
右键桌宠或托盘图标：使用同一菜单，可打开/关闭对话、历史对话和三类动画菜单。
“隐藏桌宠”后，从屏幕右下角托盘图标右键选“显示桌宠”，或双击图标恢复。
图标可能收在任务栏右下角“∧”里。
“全屏时自动隐藏”默认勾选，全屏看视频或演示时自动隐藏，退出后恢复，可取消勾选。
手动隐藏会保持，不会在退出全屏后自行出现。隐藏时暂停动画刷新，但保留播放缓存。
右键最下方“退出桌宠”彻底退出；关闭输入框只会关闭对话模式。
平时两套待机按4:1概率播放。

四、通过桌宠发任务
先在自己的电脑安装Codex并登录自己的账号，确认Codex可以正常使用，再右键打开对话模式。
仅登录ChatGPT网页不等于本机Codex已登录。官方说明：https://learn.chatgpt.com/docs/app
小输入框底部有：文件夹、历史、开启新对话、发送。输入文字后点发送，也可Ctrl+Enter。
运行时发送按钮变为停止。开启新对话不会删除旧记录。
文件夹用于选择任务文件保存的位置。重要的文件修改或额外权限会让你决定是否允许。
所有对话均通过Codex，使用你账号对应的Codex额度；没有单独的免费普通ChatGPT聊天模式。
本包不带Codex安装程序、不带作者账号、登录凭证、对话记录或额度。
需要自己的网络连接。本程序不保证模型支持所有文件类型和功能。
工作01在收到任务时播放一次并提示“主人，我收到啦”，然后接其他工作动作。
任务进行中，工作组/待机组选播概率35%/65%，组内等概率，避免连续重复；work01不参与自动循环。
自动工作动作不显示动作台词，但输入框保留，公开任务进度气泡可以显示。
历史对话和气泡会显示Codex实际提供的公开思考摘要、执行进度及回复。
这不是完整内部推理。模型未提供公开摘要时，不会生成虚假摘要。
任务成功后只播放一次点击音效和庆祝动画，气泡显示“主人，完成啦！”并报告结果。
长结果可以上下滚动，点“详情”打开对应历史。失败或停止不触发庆祝。
聊天历史保存在当前Windows用户的本地应用数据目录 BailongPet/conversations.json。
如需手动打开，可在文件资源管理器地址栏输入 %LOCALAPPDATA%/BailongPet。
桌宠和Codex共用会话记录，但主程序界面可能需要刷新或重启才能显示；不保证实时双向刷新到主程序。
不会同步到普通ChatGPT网页聊天列表。
同一桌宠对话继续发送会复用连接，以减少重复准备；网络和模型响应时间仍会影响速度。

五、额度与自动启动
额度查询需要本机Codex安装、登录、网络正常；显示的是Codex相关用量窗口，不代表ChatGPT所有模型额度。
没有Codex或暂时无法查询时，仍可正常使用离线桌宠功能。
可选：双击“开启随GPT自动启动.cmd”，以后登录Windows后助手在后台等待，打开GPT时启动桌宠。
目前识别微软商店版Codex/ChatGPT，其他安装形式未验证。
手动退出后不立即重启桌宠，下次重新打开GPT才会启动。
关闭功能用“关闭随GPT自动启动.cmd”。移动或删除文件夹前应先关闭这项功能。

六、升级、排错与卸载
升级：退出旧桌宠、关闭旧自动启动，完整解压新包到新文件夹。新程序会使用当前用户原有历史。
未签名程序可能显示未知发布者。请确认来自可信作者；遇到安全软件拦截请反馈，不要关闭杀毒软件。
缺少DLL或无法启动：确认全部解压，不要移动单个EXE，不要删除配套文件夹。
没看到桌宠：等待加载完成，检查右下角托盘和全屏自动隐藏状态，或再次运行EXE找回窗口。
查询失败：检查Codex本身是否能使用和网络/代理；临时错误会自动重试。
“检查桌宠.cmd”是离线功能自检，不会发任务或读取账号；报告生成在程序文件夹。
“app/额度查询日志.jsonl”只记录错误阶段和耗时，不记录账号凭证和额度数值。
本版本是在本机验证，不等于已经在另一台实体电脑验证。
卸载：退出桌宠，关闭自动启动，然后删除整个解压文件夹及快捷方式。
个人历史和任务文件不会随程序文件夹自动删除，请自行决定是否备份或清理。
